# Marble race custom twist
This is my twist on a merble run where 3 paths each with their own trade offs are made. The first being a path where the direction is constanly switched so the marble can never keep its speed. The 2nd being an old relible designed to be a long stable winding path to consistialy cross the line. The last being the fun gambling path where theres a good chance you never see the end.
